# Better Call Sim

Next.js website with Instagram-inspired black/yellow styling, 20 service pages, Northolt/West London context and sitewide search metadata.

Run npm ci, npm run dev, npm run typecheck, npm test, npm run build and npm run test:browser. CI builds and tests without a database or email credentials.

PDF reports are generated in the browser. Enquiries go directly through Resend to the configured inbox; no lead database is used. Calendly is disabled. See VERCEL.md for email configuration and delivery limitations, and SEARCH-READINESS.md for search settings. Historical migrations are inactive.
